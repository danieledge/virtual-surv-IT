# Code intelligence (2026-08-26). Not an analyser - these sharpen codebase ORIENTATION:
# repo_skeleton's tree-sitter tier gives exact symbols and exact line ranges for ~15
# languages, where without them it falls back to stdlib ast for Python and pattern matching
# for everything else. On a Java/Scala/C#/SQL estate, which is what surveillance systems are
# made of, that is most of the value.
#
# Optional in the strongest sense: the tier is a soft probe, so a machine that cannot
# install these behaves exactly as it did before they existed. Deliberately NOT vendored -
# ~29MB across platforms, and the core is not abi3, so it would need a wheel per Python
# version and go stale every release. Install via `virt-surv` Advanced > Code intelligence,
# or `python install_helper.py --code-intel`, or directly from this file.
tree-sitter>=0.21
# NOT pinned to a major (owner's call, 2026-08-27: "we don't want to pin an old out of
# date version"). Worth knowing what that means, because it is not merely a version choice.
# From 1.0 the pack stopped bundling grammars: the wheel carries none, and a parser request
# for an uncached language fetches a manifest and a platform bundle from a GitHub release,
# then dlopens the downloaded .so. Measured: warm cache offline is fine; COLD cache offline
# raises DownloadError, and on a proxy that black-holes rather than refuses it hangs.
#
# So the fetch is handled where it is safe rather than forbidden: install_helper's
# code_intel_step PRE-WARMS every language this team supports, once, with a human watching a
# terminal - and repo_skeleton refuses to trigger a download at runtime at all (it checks the
# grammar cache first and falls through to the pattern tier if a language is not there).
# Runtime therefore never reaches the network on any version, and an un-warmed language
# costs accuracy rather than a hang.
tree-sitter-language-pack>=0.9

# The language analysers the installer can install with no admin rights (2026-09-12, owner:
# the full check listed every language-specific analyser as "not installed" and left the
# user a list of apt/brew/go/npm commands to run by hand). bashate is the Bash style
# checker; ast-grep-cli is the PyPI build of ast-grep and is what provides the `ast-grep`
# and `sg` commands - the name scripts/check-review-tools.sh actually probes for. Both are
# plain wheels, which is why they are here rather than in the release-binary set
# (gitleaks, shfmt, shellcheck) the installer downloads from GitHub.
bashate>=2.1
ast-grep-cli>=0.28
