# Release 0.39.0: the working notes behind the changelog entry

Short cycle, four pieces of work, full detail in `CHANGELOG.md`.

- **`/status-email`.** A short progress update mid-engagement, on request or Morgan's own
  judgement, always offered and confirmed first. `--report` also produces a fuller interim
  status report. Neither is the close-only summary email or delivery report, and neither is
  gated by `SUMMARY-BEFORE-CLOSE`. The naming (`interim-update-N.txt`,
  `interim-status-report-N.md`) does that work on its own, the same trick `review-pass-N`
  already uses, so the report needed no new mechanical checks of its own.
- **A readiness nudge.** `dod_stop_gate.py` already runs the DoD check on every turn while an
  engagement is open, but it only ever speaks about defects. A clean engagement at
  delivery/close phase with nothing outstanding got no signal at all, ever, that it might be
  done. `engagement_readiness_nudge.py` closes that gap: one-time, self-suppressing, needs
  all three signals before it says anything. Found and fixed a real bug on the way: the
  dispatcher's own hook-lookup broke when its staged copy ran directly instead of being
  imported, so `dod_stop_gate.py` silently resolved as missing and produced no output.
- **Render-integrity checks.** A duplicate `[TOC]` marker, a markdown link to an anchor no
  heading produces, and a known placeholder ("UNABLE TO ASSESS") surviving into a rendered
  artifact are now caught mechanically instead of found by eye.
- **A plugin-root guard.** An engaged plugin-mode session can no longer `cd` into, or write
  into, the plugin's own installed copy - the cause of two earlier incidents (a `cd` flipping
  mode detection, a deliverable landing in the wrong tree).
- **A function-word advisory check.** A live report found a Confluence page saying
  "Compliance confirmed X" when it meant the compliance-reviewer agent, not the real
  Compliance department. `check_artifacts --advisory` now flags that pattern. Advisory only,
  since it can't always tell the two apart.
